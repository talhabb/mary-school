# مدرسة وروضة ماري | Mary School

موقع إلكتروني تعريفي وتفاعلي متكامل لـ **مدرسة وروضة ماري (Mary School)** الكائنة في حي بن الزين، الحجيرة، ولاية توقرت، الجزائر. 

تم تصميم الموقع ليكون واجهة رقمية متطورة وسريعة تسهل على الأولياء والزوار التعرف على المؤسسة، الأطوار التعليمية، روضة عدنان ولينا، والدورات التكوينية، مع إمكانية **التسجيل الأولي وإرسال الطلبات مباشرة عبر الواتساب**.

---

## 🌟 مميزات المشروع

- **تصميم متجاوب بالكامل (Responsive):** يتوافق بسلاسة مع الهواتف الذكية، الأجهزة اللوحية، والحواسيب.
- **تكامل فوري مع واتساب:** استمارة تسجيل إلكترونية تقوم بصياغة بيانات التلميذ والولي وإرسالها بضغطة زر مباشرة إلى رقم الإدارة المخصص.
- **معلومات تفصيلية شاملة:** يعرض الأطوار التعليمية (ابتدائي، متوسط، ثانوي)، روضة الأطفال، أرقام التواصل المخصصة (قسم الرجال والنساء)، والموقع الجغرافي عبر خرائط جوجل.
- **تقنيات حديثة وخفيفة:** مبني باستخدام **HTML5**، إطار العمل السريع **Tailwind CSS (عبر CDN)**، و**JavaScript** الأصلي بدون الحاجة لأي مكتبات معقدة أو عمليات بناء (Build process).

---

## 🚀 معاينة وتحميل الملفات

الموقع عبارة عن صفحة واحدة رئيسية (`index.html`) مدمج فيها التصميم والأكواد البرمجية لسهولة الرفع والتشغيل الفوري.

1. قم بتحميل أو نسخ محتوى ملف **`index.html`**.
2. يمكنك تشغيله محلياً على أي متصفح إنترنت فورا دون الحاجة لأي خادم محلي (Local Server).

---

## 📦 كيفية الرفع على GitHub Pages (نشر مجاني)

1. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub.
2. قم برفع ملف الـ **`index.html`** مباشرة إلى المستودع.
3. اذهب إلى إعدادات المستودع (**Settings**).
4. من القائمة الجانبية، اختر **Pages**.
5. تحت قسم **Build and deployment**، اختر الفرع `main` (أو `master`) واضغط **Save**.
6. خلال دقيقة واحدة، سيصبح موقعك متاحاً على الرابط الذي يوفره لك GitHub.
